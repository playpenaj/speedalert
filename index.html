HOW TO USE

🚀GETTING STARTED

📍
Mount your phone

Use a windshield or dashboard mount. Grant location permission when prompted.

▶
Press START RIDE

GPS activates, speedometer appears, speed limit detection begins immediately.

🛑
End your ride

Tap END. Trip saved automatically. Auto-ends after 10 min stationary.

🔔SOUNDS

📷
Camera within 100m

1 long beep when entering 100m radius. Repeats every 5 seconds until you pass. If already under speed limit — just 1 notification beep then silence.

⚡
1–9 km/h over limit

Short beep every 5 seconds.

⚠
10+ km/h over limit

Short beep every 3 seconds (more urgent).

📷CAMERAS

📍
Report a camera

Tap "📷 Add Camera" during any ride to save GPS coordinates.

💾
Stored permanently

Saved in browser IndexedDB. Survives restarts. Exported with all data.

⚙️TECHNOLOGY

Web GPS API
watchPosition high accuracy. Adaptive Kalman filter for smooth speed.
Nominatim OSM
Free reverse geocoding. Road name, country, maxspeed tags.
Overpass API
Speed cameras within 100–900m depending on road type.
IndexedDB
All trips and user cameras stored permanently in browser cache.
Service Worker
Background keep-alive. Push notifications when screen off.
Leaflet.js
Interactive route maps with colour-coded speed lines.
